### WHAT I'M BUILDING 👀

The code of these runs on real company data, so it stays private. Each overview explains what the system does and how it is built.

- 📊 [Attendance ETL Platform](https://github.com/IlyaMckay/attendance-etl-showcase) - consolidates access-control data from 18 offices in 11 countries for Power BI; monthly reporting went from about 6 hours to 15 minutes
- 🪑 [Office Capacity Planner](https://github.com/IlyaMckay/office-capacity-planner-showcase) - seat planning for hybrid offices, with HR-driven rosters and role-based access
- 📖 A Telegram bot that writes personalized Russian-language stories for children of families living abroad - in development

Earlier projects:

- ✔️ [Spanish verb conjugator](https://github.com/IlyaMckay/Spanish-verbs-conjugator) - a web app built for a language school: 2,000+ verbs, 29 tenses, three regional pronoun systems
- 🎧 [Audio-to-audio translator](https://github.com/IlyaMckay/Audio-to-audio-translator) - splits speech, transcribes, translates and speaks it back
- 🚨 [Incident management Telegram bot](https://github.com/IlyaMckay/Incident-Mgmt-Telegram-Bot) - three services (bot, REST API, admin page) on PostgreSQL, modeled on ITIL incident management
